# price-alert-bot
A Telegram bot that checks the Bitcoin price every 30 minutes and sends an instant alert when it moves above or below a set level.

## Features
- Runs 24/7 for free on GitHub Actions
- Alerts sent straight to Telegram
- Easy to customize: any coin, any price level
